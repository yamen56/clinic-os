# Brand assets

These are the real Makan assets, extracted from the brand handoff bundle.

`logo-mark-primary.png` is the blue double-wave mark on transparency. Replacing
any file here updates every surface automatically — no code change needed.

Rules from the brand spec, worth repeating here:

- Use the mark **alone** — never set "Makan Scaling" in type beside it in app chrome.
- Never redraw it in SVG/CSS, never recolor it, never add effects.
- Clear space ≥ the mark's own height. Minimum size 20px.

Optional additions the app will use if present:

| File | Where it's used |
|---|---|
| `logo-mark-primary.png` | Sidebar (64px), login (72px), favicon |
| `bg-aurora-grain.png` | Login background, in place of the CSS gradient |
